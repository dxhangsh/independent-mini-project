## 三、剩余操作步骤（按顺序做）

### 步骤 1 · 真机 PWA 安装验证（约 10 分钟）

**桌面端：**
1. `run.ps1` 启动 → Chrome/Edge 打开 `http://127.0.0.1:8765`
2. 地址栏右侧出现安装图标，或点页面顶栏「📲 安装」→ 安装后从桌面/开始菜单打开

**手机端（与电脑同一 WiFi）：**
1. `powershell -ExecutionPolicy Bypass -File run.ps1 -Lan`——自动探测局域网 IP 并生成自签证书，控制台会显示形如 `https://192.168.31.8:8765` 的地址
2. 手机浏览器访问该地址 → 证书警告点「高级 → 继续前往」（自签名正常现象）
3. 浏览器菜单 →「添加到主屏幕」→ 桌面出现价签图标，独立窗口打开
4. **注意**：换网络后 IP 会变，重跑一次 `-Lan` 即可自动重新生成证书

### 步骤 2 · 试用反馈（3 人 × 5-10 分钟）

1. 邀请 3 位同学，**不给任何说明**，只让他们靠界面提示独立完成「扫描 → 复核 → 落盘」

3. 如果反馈暴露 bug：记入错误日志 → 修复 → 在反馈表汇总区注明"已当场修复"
4. 填完写三句话总结（三人是否都独立完成 / 最高频卡点 / 进 v2 的建议）

## 四、常用命令速查

> **最省事的方式**：直接双击项目根目录的 **`启动 PicNamer.bat`**（等效于本机模式，已处理执行策略与编码问题）。

```powershell
# 本机启动（自动开浏览器）
powershell -ExecutionPolicy Bypass -File run.ps1

# 局域网 HTTPS 启动（手机 PWA 安装用）
powershell -ExecutionPolicy Bypass -File run.ps1 -Lan

# 全量测试（在 backend/ 下）
..\.venv\Scripts\python.exe -m pytest tests -q

# 重生成 PWA 图标（改设计后）
.\.venv\Scripts\python.exe tools\make_icons.py

# 重新生成局域网证书（IP 变了；-Lan 会自动做，无需手动）
.\.venv\Scripts\python.exe tools\make_cert.py --ip <新IP>
```

**提醒**：改了 `frontend/` 下任何文件后，把 `frontend/sw.js` 顶部的 `CACHE = "picnamer-v1"` 版本号 +1（如 `v2`），已安装的客户端下次打开会自动更新。

## 五、常见问题排查速查

| 现象 | 处理 |
|---|---|
| 改了图/换图后复核页还是老图 | ①确认后端已重启（bat 关掉重开）②批量面板对应目录点「**重新扫描**」③浏览器普通刷新两次（SW 网络优先会自动拿新版） |
| 页面样式/功能像是旧版 | 重启后端 → 普通 F5 两次；仍不行则 F12 → 存储 → 清除该站点数据 → 刷新 |
| 启动脚本报解析错误 | 已修复（ERR-008，BOM）；若再现请把红字发我 |
| 落盘被"已阻止" | 红框里现在会写明原因与处理方式（改名/跳过/放行），按提示操作即可 |
| 端口 8765 被占 | 关掉旧的 PicNamer 窗口再启动 |
