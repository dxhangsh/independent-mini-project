## 快速开始

1. **最省事**：双击项目根目录的「启动 PicNamer.bat」；或运行 `run.ps1`（首次自动建虚拟环境并装依赖，随后启动服务并打开浏览器；地址为 `http://127.0.0.1:8765`）
2. 确保本机 Ollama 在跑且已拉取 `qwen3-vl:8b`（设置页可测连接；也可在设置页切换云端 API）
3. 工作台粘贴**一个或多个**文件夹路径（每行一个）→ 等待 AI 建议 → 逐图复核 → 落盘；中断后「继续上次批次」自动跳过已完成目录

## 安装为 App（PWA）

- **本机**：Chrome/Edge 打开 `http://127.0.0.1:8765`，地址栏右侧点「安装」，或页面顶栏「📲 安装」按钮
- **手机**（与电脑同一局域网）：运行 `run.ps1 -Lan`（自动生成自签 HTTPS 证书并监听全网卡），手机浏览器访问 `https://<局域网IP>:8765`，首次出现证书警告属正常（自签名），点「高级 → 继续前往」，然后菜单选「添加到主屏幕」；局域网 IP 变更后重跑一次即可

## 开发

```powershell
cd backend
..\.venv\Scripts\python.exe -m pytest tests -q   # 92 用例
.\.venv\Scripts\python.exe tools\make_icons.py   # 重生成 PWA 图标（改设计后）
```

> 前端改动后请把 `frontend/sw.js` 里的 `CACHE` 版本号 +1（SW 现为网络优先，版本号主要影响离线兜底与已打开页面的刷新速度）。
> 目录内容有变动（加/删/换图）后：重提交同批目录会自动重扫（按内容签名检测，ADR-010）；或在批量面板对应目录行点「**重新扫描**」立即重扫单个目录。
